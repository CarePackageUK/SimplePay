# SimplePay MVP

A mobile-friendly UK payroll product prototype focused on making payroll understandable for non-specialists.

## Demo features
- Dashboard and next-payday summary
- Employee list and profiles
- Add employee flow
- Payroll review
- Unusual-pay warning
- Overtime breakdown
- Payroll approval/completion flow
- Time and HMRC settings placeholders

## Important
This is a prototype using dummy data. It does not submit to HMRC or move money.

For GitHub Pages, publish from the root of the main branch.
